# Reglas de Salida y Formato

- **Formato de código:** No reescribas archivos completos cuando hagas modificaciones. 
- Devuelve únicamente el **diff unificado** (estilo git diff) o solo el bloque de función/líneas específicas que cambian.
- Mantén las explicaciones previas y posteriores al mínimo indispensable (respuestas concisas y directas).
